markdown# SS International — Project Design System This is the master design system for the SSI website. Every component, page, and edit must follow these rules. Do NOT deviate without explicit instruction. --- ## Project Context SS International Industries LLP is a precision rubber sealing manufacturer based in India. 25 years of expertise. Serves 8 industries: Automotive, Roadways, Architecture, Railways, Shipping, Power Distribution, Mining, Infrastructure. The website is a B2B premium manufacturing site — buyers are procurement heads and engineers at OEMs. The aesthetic must feel like a confident global manufacturer (think Bosch, Trelleborg, Tata Motors), NOT a SaaS startup or AI tool. The current direction is **light theme with strategic dark sections**, premium editorial typography, real industrial photography. --- ## Brand Colors (use ONLY these) --blue:        #1B91FF   /* Primary accent — CTAs, links, eyebrow lines, active states / --black:       #141414   / Forge Black — used for dark sections + primary text / --mist:        #D7D7D6   / Muted text, secondary headlines, dividers / --smoke:       #A8A8A8   / Tertiary text, captions, labels / --white:       #FFFFFF   / Card backgrounds, light section backgrounds / --bg-light:    #F8F8F8   / Default light section background / --border:      #E8E8E8   / All dividers and card borders on light bg / --bronze:      #B8935A   / Bronze/gold secondary accent — sparing use, tertiary highlights and icons / --slate:       #5B6B82   / Slate tertiary — sparing use, secondary text or muted UI accents */ **Banned:** - No purple, green, red, orange, yellow accents - No gradient backgrounds (mesh, radial, or otherwise) anywhere except subtle dark overlays on hero images - No "AI startup" blue/purple gradients on text or buttons - No random Tailwind colors (e.g. `blue-500`, `gray-900`) — use the brand hex codes --- ## Typography **Two font families, no others:** --font-barlow: 'Barlow'   /* All headings, navigation, buttons, eyebrows / --font-inter:  'Inter'    / All body text, descriptions, captions, labels */ **Headline rules:** - Always uppercase - `fontWeight: 900` - `letterSpacing: -2px` to `-3px` (negative tracking for tight, premium feel) - `lineHeight: 0.95` to `1.0` - Two-line pattern is preferred: first line `#141414`, second line `#D7D7D6` (muted) for visual hierarchy **Eyebrow pattern (use above every section heading):** [ 24-32px blue line ] CAPABILITIES - Blue horizontal line (`width: 24-32px`, `height: 1.5px`, `background: #1B91FF`) - Followed by 10px uppercase Inter text in `#1B91FF` - `letterSpacing: 3px` - `fontWeight: 700` **Body text:** - 13–15px, `color: #555` or `#666` for primary, `#888` or `#A8A8A8` for secondary - `lineHeight: 1.7` to `1.85` - Use Inter, not Barlow --- ## Component Rules ### Buttons (MANDATORY — these values are locked) Primary button: background: #1B91FF color: #fff padding: 14px 32px (or 16px 36px for hero CTAs) borderRadius: 50px        /* PILL SHAPE — never square, never 4px, never 8px */ fontSize: 12-13px fontWeight: 700 letterSpacing: 0.5px textTransform: uppercase fontFamily: var(--font-barlow) Hover: background: #0f7ae0 Secondary button: background: transparent  (light bg) or rgba(255,255,255,0.08) (dark bg) border: 1.5px solid #D7D7D6 (light) or rgba(255,255,255,0.25) (dark) color: #141414 (light) or #fff (dark) Same padding/radius/typography as primary **NEVER use square buttons. NEVER use 4px or 8px radius on buttons.** ### Cards - `borderRadius: 12px` to `16px` (image cards) or `8px` (stat cards) - Image cards: full-bleed image + dark gradient overlay (`linear-gradient(to bottom, rgba(0,0,0,0.1) 30%, rgba(0,0,0,0.85) 100%)`) + content sitting on bottom 40% - Card backgrounds on light sections: `#FFFFFF` with `border: 1px solid #E8E8E8` ### Eyebrow + Heading section header pattern Used at the top of every major section: ```tsx <div style={{ display: "flex", alignItems: "center", gap: 14, marginBottom: 18 }}> <div style={{ width: 32, height: 1.5, background: "#1B91FF" }}/> <span style={{ color: "#1B91FF", fontSize: 10, fontWeight: 700, letterSpacing: "3px", textTransform: "uppercase", fontFamily: "var(--font-inter)", }}>SECTION LABEL</span> </div> <h2 style={{ color: "#141414", fontSize: "clamp(32px, 4vw, 52px)", fontWeight: 900, lineHeight: 0.95, letterSpacing: "-2px", textTransform: "uppercase", margin: 0, }}> Headline Line One.<br/> <span style={{ color: "#D7D7D6" }}>Muted Second Line.</span> </h2> ``` ### Spacing - Section padding: `100px 72px` for major sections, `120px 52px` for hero - Grid gaps: `14-20px` between cards, `1-2px` for tight grids - Use multiples of 4 or 8 — never random numbers --- ## Animation (use Framer Motion ONLY) Framer Motion is installed. **Stop writing inline `onMouseEnter`/`onMouseLeave` JavaScript handlers.** Replace them with `motion` components and `whileHover`, `whileInView`, `useInView`. **Default animation patterns:** ```tsx // Section reveal on scroll <motion.div initial={{ opacity: 0, y: 24 }} whileInView={{ opacity: 1, y: 0 }} viewport={{ once: true, amount: 0.2 }} transition={{ duration: 0.6, ease: [0.25, 0.46, 0.45, 0.94] }} > // Stagger children (cards in a grid) const containerVariants = { visible: { transition: { staggerChildren: 0.08 } } }; const cardVariants = { hidden: { opacity: 0, y: 24 }, visible: { opacity: 1, y: 0, transition: { duration: 0.5 } } }; // Image zoom on card hover <motion.div whileHover={{ scale: 1.06 }} transition={{ duration: 0.6, ease: [0.25, 0.46, 0.45, 0.94] }}> // Button hover <motion.button whileHover={{ y: -2 }} whileTap={{ scale: 0.98 }} transition={{ duration: 0.15 }}> // Subtle card tilt + image zoom (BrandStatement pattern) <motion.div whileHover={{ rotate: 1 }} transition={{ duration: 0.5 }}> <motion.img whileHover={{ scale: 1.06 }} /> </motion.div> ``` **Banned:** - No bouncy/elastic spring animations (this is B2B, not consumer) - No spinning, flashing, or attention-grabbing motion - No animations longer than 0.6s - No glowing pulses or particle effects --- ## Copy Voice & Tone - Confident, technical, understated - Numbers and specifications are credibility — use them ("25+ years", "8 industries", "EN45545 certified", "DIN 7863") - Short headlines, periods at the end for emphasis: "Precision. Sealing for Automotive." - Two-line headline pattern: bold statement + muted clarifier - Eyebrows are SHORT (2-4 words): "CAPABILITIES", "INDUSTRIES WE SERVE", "PRODUCT CATEGORIES" - Never use exclamation marks, never use emoji, never use casual SaaS-speak ("Let's build something amazing!") - Industry standards are name-dropped as proof: DIN 7863, BS 6853, ISO 3934, EN 45545, ASTM C-864 **Banned phrases:** - "Innovative solutions" - "Cutting-edge technology" - "Industry-leading" - "Best-in-class" - "Empowering businesses" - Any generic B2B filler --- ## Images - Always use `<img>` tags (not Next/Image yet — kept simple for prototyping) - Always include `style={{ objectFit: "cover", display: "block" }}` - Image-card pattern: full-bleed image + dark gradient overlay (`linear-gradient(to bottom, rgba(0,0,0,0.1) 30%, rgba(0,0,0,0.85) 100%)`) + content overlay at bottom - Source: Unsplash and Pexels with verified URLs only - For hover: zoom image to `scale(1.06)` over `0.6s` cubic-bezier `(0.25, 0.46, 0.45, 0.94)` --- ## Section Background Rhythm Don't make every section the same background color. Use this rhythm: Hero            — full-bleed image with dark overlay BrandStatement  — #ffffff IndustriesGrid  — #f8f8f8 Technologies    — #141414 (DARK BAND — breaks the light flow) ProductsPreview — #f8f8f8 CTABanner       — #141414 (DARK) Footer          — #f8f8f8 This creates contrast and visual rhythm as the user scrolls. --- ## Avoid the Generic AI Aesthetic This is a manufacturing brand. The site should look like a confident global industrial company, not a SaaS landing page. **Specifically banned:** - No glowing orbs, particles, or "magic" effects - No purple/blue mesh gradients as backgrounds - No floating 3D objects without industrial purpose - No oversized emoji as section icons (use proper SVG line icons) - No pastel colors anywhere - No "card with rainbow border on hover" tricks - No glassmorphism (`backdrop-filter: blur`) except very sparingly on dark hero overlays - No infinite-scroll marquee strips of fake "trusted by" logos unless they are real clients --- ## File Structure All components live in `src/components/`. Each section is its own `.tsx` file: - `Nav.tsx`, `HeroSection.tsx`, `BrandStatement.tsx`, `IndustriesSection.tsx`, `TechnologiesSection.tsx`, `ProductsPreview.tsx`, `CTABanner.tsx`, `Footer.tsx` Pages live in `src/app/`. The homepage is `src/app/page.tsx`. When creating new components, match the existing style. Read at least 2 existing components before generating new code so you stay consistent. --- ## Iteration Rules 1. **When asked to make a change**, only change the specific thing requested. Do not redesign the whole component. 2. **When in doubt about a value**, read the existing component and copy from it. Don't invent new values. 3. **Before writing new code**, scan the existing files in `src/components/` to learn the established patterns. 4. **Confirm assumptions** before doing destructive rewrites. Ask if unclear. 5. **Test the build** with `npm run dev` mentally — don't write code that breaks imports.
